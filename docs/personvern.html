Personvernerklæring

AI-skanner er et gratis program med åpen kildekode som finner AI på en Windows-PC. Det kjører bare på PC-en din. Det finnes ingen konto, ingen sky, ingen analyse og ingen reklame. Utvikleren får aldri se noe fra PC-en din.

Hva programmet leser på PC-en

For å finne AI leser programmet, bare lokalt og bare mens vinduet er åpent:

  • navn og stier til programmer, filer og mapper, og filhoder på modellfiler
  • prosesser som kjører, og kommandolinjene til AI-programmer (maskert, aldri vist)
  • Windows-registeret, Windows' egne logger og brukerspor, og navnet på brukerkontoen og PC-en
  • i nettlesere: hvilke AI-nettsteder som er besøkt (domene, antall besøk og tidspunkt), utvidelser og innebygde modeller
  • åpne nettverksforbindelser fra AI-programmer (adresse og land), og lokale AI-servere på PC-en selv (127.0.0.1)

Programmet leser aldri passord, informasjonskapsler, skjemadata, verdier av nøkler, prosessminne eller samtaler med AI.

Hva som sendes ut

  • NVD: for å sjekke kjente sikkerhetshull sendes bare produktnavnet (for eksempel «ollama») over HTTPS til NVD, en tjeneste fra amerikanske NIST. NIST ser IP-adressen din, slik alle nettsteder gjør.
  • DNS: programmet slår opp adressene til en fast liste med kjente AI-tjenester hos DNS-serveren PC-en bruker. Lista er den samme for alle og sier ingenting om PC-en.

Ingenting annet sendes. Aldri PC-navn, brukernavn, stier eller funn. Ingen data selges eller deles med noen.

Hva som lagres

Ingenting blir igjen etter søket. Vinduet bruker en midlertidig mappe (i AppData) som slettes når programmet lukkes. Det eneste som lagres, er det du selv velger: en rapport du lagrer, eller revisjonsloggen i Dokumenter\AI-skanner hvis du slår den på. Disse filene er dine og forlater ikke PC-en.

Dine valg

  • Du velger selv om programmet skal søke, og om det skal søke som bruker eller administrator.
  • IT kan slå av NVD-oppslagene og nettleserhistorikken med --uten-nvd og --uten-historikk.
  • Du kan slette rapporter og revisjonslogger når du vil. Avinstallering i Windows, eller å slette AISkanner.exe, fjerner programmet helt.
  • Alt programmet leser, vises under «Datagrunnlag» i vinduet. Kildekoden er åpen: github.com/UUnreal/AIscanner.

Barn

Programmet samler ikke inn opplysninger om noen, heller ikke barn.

Privacy policy

AI Scanner is a free, open-source program that finds AI on a Windows PC. It runs only on your PC. There is no account, no cloud, no analytics and no ads. The developer never sees anything from your PC.

What the program reads on the PC

To find AI, the program reads, locally and only while its window is open:

  • names and paths of programs, files and folders, and the headers of model files
  • running processes, and the command lines of AI programs (masked, never shown)
  • the Windows registry, Windows' own logs and usage traces, and the user account and PC name
  • in browsers: which AI websites were visited (domain, number of visits and time), extensions and built-in models
  • open network connections of AI programs (address and country), and local AI servers on the PC itself (127.0.0.1)

The program never reads passwords, cookies, form data, key values, process memory or AI chats.

What is sent out

  • NVD: to check known vulnerabilities, only the product name (for example «ollama») is sent over HTTPS to NVD, a service of the US NIST. NIST sees your IP address, as every website does.
  • DNS: the program looks up the addresses of a fixed list of known AI services with the DNS server the PC uses. The list is the same for everyone and says nothing about the PC.

Nothing else is sent. Never the PC name, user name, paths or findings. No data is sold or shared with anyone.

What is stored

Nothing is left after the scan. The window uses a temporary folder (in AppData) that is deleted when the program closes. The only things stored are what you choose: a report you save, or the audit log in Documents\AI-skanner if you turn it on. These files are yours and do not leave the PC.

Your choices

  • You decide whether the program scans, and whether it scans as user or administrator.
  • IT can turn off the NVD lookups and browser history with --uten-nvd and --uten-historikk.
  • You can delete reports and audit logs at any time. Uninstalling it in Windows, or deleting AISkanner.exe, removes the program completely.
  • Everything the program reads is shown under «Data basis» in the window. The source code is open: github.com/UUnreal/AIscanner.

Children

The program collects no information about anyone, including children.
